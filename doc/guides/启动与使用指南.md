## 2. 配置方式

### 2.1 环境变量配置

项目通过 [ai-engine/config.py](../../ai-engine/config.py) 统一读取环境变量，**不要将真实 API Key 写入代码或配置文件**。

| 用途 | 环境变量 | 默认值/说明 |
|------|---------|-----------|
| **业务Agent（5个）** | `DEEPSEEK_API_KEY` | DeepSeek API Key（兼容兜底 `LLM_API_KEY`） |
| 业务Agent | `LLM_BASE_URL` | `https://api.deepseek.com/v1` |
| 业务Agent | `LLM_MODEL` | `deepseek-chat`（支持 `deepseek-v4-flash`） |
| **PageAgent/SunPilot** | `ALI_API_KEY` | 阿里云百炼 DashScope API Key |
| PageAgent | `PAGE_AGENT_LLM_BASE_URL` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| PageAgent | `PAGE_AGENT_LLM_MODEL` | `qwen-plus` |
| **MySQL数据库** | `MYSQL_ROOT_PASSWORD` | 用于自动拼接本地 `ticket_agent` 连接串 |
| MySQL（可选） | `DATABASE_URL` | 手动指定连接串（非本地库时使用） |
| **管理员鉴权** | `ADMIN_API_KEY` | 用于保护 `/close` 和 `/config/reload` 端点 |

### 2.2 配置方式（Windows）

**推荐方式：系统级环境变量**

1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
2. 在"用户变量"或"系统变量"中新建：
   - `DEEPSEEK_API_KEY` = `sk-...`
   - `ALI_API_KEY` = `sk-...`
   - `MYSQL_ROOT_PASSWORD` = `your_mysql_password`
   - `ADMIN_API_KEY` = `your_admin_secret` （可选，用于保护管理端点）
3. 保存后重启终端（或重启系统）

**临时方式：PowerShell 当前会话**
```powershell
$env:DEEPSEEK_API_KEY="sk-..."
$env:ALI_API_KEY="sk-..."
$env:MYSQL_ROOT_PASSWORD="your_mysql_password"
$env:ADMIN_API_KEY="your_admin_secret"
```
> ⚠️ 临时方式在关闭终端后失效，仅用于测试。

### 2.3 数据库连接

**自动模式（推荐）：**
- 设置 `MYSQL_ROOT_PASSWORD` 环境变量
- 项目自动拼接连接串：`mysql+asyncmy://root:***@127.0.0.1:3306/ticket_agent?charset=utf8mb4`

**手动模式（连接远程库）：**
```powershell
$env:DATABASE_URL="mysql+asyncmy://user:password@remote_host:3306/ticket_agent?charset=utf8mb4"
```

## 5. 完整演示流程

### 5.1 发单流程（通话记录 → 标准工单）

1. 打开 `http://127.0.0.1:5174/dispatch`
2. 从通话记录列表中选择一条样本
3. 点击"生成发单草稿"
4. 后端配置驱动的字段提取引擎自动抽取 `customerId`、`cardLast4`、`phone` 等字段
5. SunPilot 面板显示建议操作，可执行"填写表单"、"提交发单"
6. 点击"提交发单" → 工单进入回单队列

### 5.2 回单流程（5 Agent 协作处理）

1. 打开 `http://127.0.0.1:5174/reply`
2. 从工单列表中选择一条 `IN_PROGRESS` 或 `PENDING_HUMAN_REVIEW` 工单
3. 点击"开始AI处理"

**后端 5 Agent 协作链路：**
- **Classifier Agent**: 场景分类（协商还款、伪冒预防、市场企划等 7+1 场景）
- **Intake Agent**: 字段提取（配置驱动 + 置信度检查 + LLM merge）
- **Resolution Agent**: 工具选择与参数构建（确定性 fast-lane + LLM slow-lane）
- **Escalation Agent**: 风险门控与升级决策（LLM 综合评估 can_auto_proceed）
- **Notification Agent**: 回单生成与结案建议

4. 前端实时展示：
   - 外部系统核验结果（Mock Tools 审计日志）
   - 待补充信息（missing_fields）
   - 处理依据（evidence_ids）
   - 回单草稿（reply_draft）

5. SunPilot 面板自动带入回单草稿，可执行"定位证据"、"补充字段"
6. **人工复核后结案**（必须走主系统人工操作，自动流程不能直接结案）

### 5.3 安全边界

✅ **自动流程可以：**
- 分类、抽取、选工具、生成回单草稿
- 标记工单为 `PENDING_HUMAN_REVIEW`
- 通过 `closureSuggestion.canClose` 建议结案

❌ **自动流程不能：**
- 直接将工单状态改为 `CLOSED`
- 绕过人工复核直接结案
- 执行 PageAgent 的 save/close/transfer 操作（ReAct 通道白名单拦截）

## 6. 配置驱动架构说明

### 6.1 workflow_config.json

**位置**: [ai-engine/data/workflow_config.json](../../ai-engine/data/workflow_config.json)

**作用**：
- **场景定义**: 7 个业务场景（协商还款、伪冒预防、伪冒调查、客户经营、市场企划、调单扣款、征信）
- **字段配置**: `commonFields`（通用）+ `specificFields`（场景特定）
- **提取规则**: `extractRule`（regex/context/keyword/literal）
- **工具映射**: `availableTools`、`recommendedTool`
- **场景检测**: `detection.patterns`、`detection.priority`

**示例**（commonFields）：
```json
"commonFields": [
  {
    "name": "customerId",
    "label": "客户号",
    "extractRule": {
      "type": "regex",
      "pattern": "(C\\d{5,})"
    }
  },
  {
    "name": "phone",
    "label": "手机号",
    "extractRule": {
      "type": "regex",
      "pattern": "(1\\d{2}\\*{4}\\d{4}|1\\d{10})"
    },
    "default": "待补充"
  }
]
```

### 6.2 配置热加载（需要 ADMIN_API_KEY）

修改 `workflow_config.json` 后，无需重启后端：

```bash
curl -X POST http://127.0.0.1:8000/api/config/reload \
  -H "X-API-Key: your_admin_secret"
```

**响应**：
```json
{
  "status": "reloaded",
  "timestamp": "2026-07-26T10:30:00"
}
```

> ⚠️ 如果新配置校验失败，会保留旧配置并返回 500 错误。

## 7. SunPilot / PageAgent 使用

### 7.1 两条通道

**确定性通道（Deterministic）：**
- 后端生成 `PageTask`（包含 `scrollToRegion`、`clickSemantic`、`fillFormByTargets`）
- 前端严格按 PageTask 执行，白名单验证
- **用于**：发单提交、回单字段填充

**ReAct 通道（LLM 驱动）：**
- 用户在 SunPilot 输入框输入自然语言任务
- PageAgent 自主 observe → think → act（最多 15 步）
- **安全边界**：白名单强制执行，禁用 `execute_javascript`、`click_element_by_index`
- **阻断列表**：`page-agent-close-ticket`、`page-agent-save-draft`、`draft-submit`

### 7.2 SunPilot 设置面板

点击 SunPilot 输入框底部的"设置"按钮：
- **临时切换** PageAgent 的 API Key / Model / Base URL
- **仅影响当前后端进程**，重启后失效
- 适合演示现场临时切换模型

### 7.3 PageAgent 安全修复（v2.0）

✅ **P0-3**: ReAct 通道白名单强制执行（代码硬门控）  
✅ **P0-4**: 物理移除 `execute_javascript` 工具  
✅ 禁用 `click_element_by_index`（防止任意 DOM 点击）  
✅ `click_semantic_target` 执行前验证 `BLOCKED_CLICK_TARGETS`

## 11. 常见问题

### Q1: DeepSeek API Key 无效？

**检查步骤：**
1. 确认环境变量 `DEEPSEEK_API_KEY` 已设置（PowerShell: `$env:DEEPSEEK_API_KEY`）
2. 重启后端（环境变量在后端启动时读取）
3. 检查 Key 是否有效（访问 DeepSeek 控制台验证）

### Q2: 阿里云百炼 API Key 无效？

**检查步骤：**
1. 确认环境变量 `ALI_API_KEY` 已设置
2. 重启后端
3. 检查 Key 是否有 DashScope 权限

### Q3: MySQL 连接失败？

**错误示例：**
```text
sqlalchemy.exc.OperationalError: (2003, "Can't connect to MySQL server on '127.0.0.1:3306'")
```

**解决方案：**
1. 确认 MySQL 服务已启动
2. 确认 `MYSQL_ROOT_PASSWORD` 环境变量正确
3. 测试连接：`mysql -u root -p -h 127.0.0.1`
4. 如果连接远程库，手动设置 `DATABASE_URL`

### Q4: 前端空白或接口失败？

**检查步骤：**
1. 确认后端运行在 `http://127.0.0.1:8000`（查看终端输出）
2. 确认前端运行在 `http://127.0.0.1:5174`
3. 打开浏览器开发者工具（F12）查看 Network 标签页
4. 检查是否有 CORS 错误或 404 错误

### Q5: ADMIN_API_KEY not set 警告？

**这是预期警告**，不影响核心功能。仅影响以下端点：
- `POST /api/tickets/{id}/close`（结案）
- `POST /api/config/reload`（配置热加载）

**解决方案：**
设置环境变量 `ADMIN_API_KEY`，然后重启后端。

### Q6: ImportError: cannot import name 'xxx'？

**最近修复的导入错误：**
- `pipeline_context_repository.py` 的 `db_pool` → 已修复为 `_get_engine()`

**排查步骤：**
1. 运行语法检查：`uv run python -m compileall ai-engine`
2. 测试导入：`cd ai-engine && uv run python -c "import sys; sys.path.insert(0, '.'); import main"`
3. 如果仍有错误，查看具体错误信息并定位文件

### Q7: 配置修改后不生效？

**原因：** 配置在后端启动时加载，运行时修改需要热加载。

**解决方案：**
- **方式1（推荐）**：调用热加载 API（需要 ADMIN_API_KEY）
  ```bash
  curl -X POST http://127.0.0.1:8000/api/config/reload \
    -H "X-API-Key: your_admin_secret"
  ```
- **方式2**：重启后端（Ctrl+C 停止，重新运行 uvicorn）

## 12. 架构版本说明

**v2.0（2026-07-26）架构优化：**

✅ **P0 安全修复**
- 删除危险的 `/api/llm/proxy/config` 端点

✅ **工程质量提升**
- 重试策略统一：所有 5 个 Agent 开启网络异常重试
- 风险门控去重：单一决策路径
