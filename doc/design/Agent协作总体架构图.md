## 核心数据流（按时间顺序）

```
发单侧 (1 次 LLM):
  通话记录 ──→ 发单Agent ──→ ticketDraft ──→ 动态表单 ──→ 提交 ──→ 工单创建

回单侧 (2-4 次 LLM):
  工单原文 ──→ 5 Agent 管道 ──→ AiProcessResult ──→ SSE ──→ Store
                                                ──→ bridge ──→ SunPilot
                                                ──→ pageTask ──→ PageAgent

两条线并行不冲突:
  SSE trace  → SunPilot 展示进度     (纯信息流)
  pageTask   → PageAgent 执行页面操作 (操作流)
```

---

## 设计原则

| 原则 | 体现 |
|------|------|
| **配置驱动** | 700+ 场景差异在 workflow_config.json，Agent 代码不变 |
| **双脑解耦** | 后端 Agent 管 what，PageAgent 管 how，通过 observation/PageTask 通信 |
| **分层隔离** | Agent 不感知 Mock/真实系统，换 executor 层即可 |
| **降级兜底** | vue 页面走确定性执行(快)，外部系统走 ReAct(慢但通用) |
```
