# 工单系统 - 各分类字段结构详解

> 基于50张Demo截图逐类对照整理

---

## 一、通用字段（所有工单类型共用）

无论是发单还是回单，以下字段是所有工单类型都有的：

| 字段 | 类型 | 说明 |
|------|------|------|
| 发单编号 | 自动生成 | 17位数字，前缀标识业务类型 |
| 填表人姓名 | 自动填入 | 当前登录用户 |
| 分机号 | 文本 | 联系电话 |
| 件别 | 下拉 | 一般件 / 紧急件 |
| 处理状态 | 状态 | 待处理 / 暂存 / 系统结案 / 正常 |
| 发单内容 | 富文本 | 自由编辑区（支持 Enter 换行） |
| 具体内容 | 富文本 | 详细描述 |
| 是否需要回复 | 单选 | 是 / 否 |
| 补充信息 | 文本 | 额外补充说明 |
| 规定回件日期 | 日期 | SLA 截止时间 |
| 操作按钮 | 按钮组 | **发送**、Enter换行、Ctl+Enter |

## 二、底部系统选择区（所有类型通用）

发单表单底部有个可滚动的"选择系统"区域，用于关联后端系统：

| 系统名 | 说明 |
|--------|------|
| 积分系统 | 积分相关 |
| 借记卡发卡调扣 | 借记卡交易调单 |
| 借记卡收单调扣 | 借记卡收单 |
| 开户管理系统 | 账户开户 |
| 客户综合服务系统 | 客户服务 |
| 会总账系统 | 账务 |
| 卡管理系统 | 卡片管理 |
| 进度服务系统 | 进度跟踪 |
| 自动化剔退 | 自动复核剔退 |

## 三、各分类特有字段（按一级分类展开）

### 3.1 伪冒 - 风险预防组（前缀 12xxxx）

**触发场景：** 投诉引导、伪冒交易预警

| 字段 | 类型 | 特有/通用 | 说明 |
|------|------|-----------|------|
| CALLID | 文本 | **特有** | 通话记录ID |
| 主叫号 | 文本 | **特有** | 来电号码 |
| 是否消费者本人 | 单选 | **特有** | 是/否 |
| 投诉人姓名 | 文本 | **特有** | 投诉人 |
| 投诉人证件号 | 文本 | **特有** | 投诉人身份证 |
| 投诉人证件类型 | 下拉 | **特有** | 身份证等 |
| 投诉人手机号 | 文本 | **特有** | 投诉人联系方式 |
| 案件编号 | 文本 | **特有** | 伪冒案件编号（如 801114413001） |
| 工单类别 | 下拉 | **特有** | 投诉引导(接受投调引导) 等 |
| 来电目的 | 文本 | **特有** | 如"已联系关机" |
| 已建案 | 状态 | **特有** | 是否已立案 |
| 被投诉内容 | 富文本 | **特有** | 投诉详情 |
| 主体诉求 | 富文本 | **特有** | 核心诉求描述 |
| 其他说明 | 文本 | **特有** | 补充 |
| 业务类型 | 下拉 | 通用 | - |
| 业务办理渠道 | 下拉 | **特有** | 自有电子渠道 等 |
| 个人业务 | 标签 | **特有** | 业务分类标记 |
| 投诉人信息标签 | 信息组 | **特有** | 投诉人相关信息区 |

**按钮区：** 工单定制 → 派单设置 → 12378工单转派 → 工单查询 → 我提交的工单 → 工单转派 → 多元工单转派 → 催收工单查询 → 处理工单查询 → 催收待处理工单查询 → 征信贷后工单转派 → 工单报表 → 数据看板

### 3.2 伪冒 - 伪冒调查组（前缀 13xxxx）

**触发场景：** 伪冒案件调查、客户两核身不过

| 字段 | 类型 | 特有/通用 | 说明 |
|------|------|-----------|------|
| 关联工单号 | 文本 | 通用 | 关联历史工单 |
| 客户号 | 文本 | 通用 | 如 0201357806 |
| 客户姓名 | 文本 | 通用 | - |
| 证件号 | 文本 | 通用 | 身份证号 |
| 手机号 | 文本 | 通用 | - |
| 预警等级 | 下拉 | 通用 | 风险等级 |
| 客户标签 | 标签 | 通用 | - |
| 卡片列表 | 下拉/多选 | **特有** | BLOCK 状态卡片 |
| 备注 | 文本 | **特有** | 卡片备注（如卡号段） |
| X-DK | 文本 | **特有** | 未知字段 |
| 业务类型 | 下拉 | 通用 | 调查类管制解管 |
| 业务细分类型 | 下拉 | 通用 | 其他 |

**典型发单内容模板：**
```
[客户要求]
客户卡片被管制

[补充说明]
麻烦贵部处理
谢谢!
```

**SLA：** 2026-07-24 23:59:59（T+2自然日）

## 六、设计建议

### 数据模型设计

```
work_order
├── base_fields（通用）
│   ├── order_no: str(17)           # 发单编号
│   ├── order_type: enum            # 一级分类（编号前缀推断）
│   ├── biz_type: str               # 业务类型（下拉）
│   ├── biz_sub_type: str           # 业务细分类型（下拉）
│   ├── priority: enum              # 一般件/紧急件
│   ├── status: enum                # 待处理/暂存/正常/系统结案
│   ├── creator_name: str           # 填表人
│   ├── extension: str              # 分机号
│   ├── content: text               # 发单内容
│   ├── detail: text                # 具体内容
│   ├── need_reply: bool            # 是否需回复
│   ├── supplement: text            # 补充信息
│   ├── deadline: datetime          # 规定回件日期(SLA)
│   ├── attachments: [file]         # 附件
│   └── related_systems: [str]      # 关联后端系统
│
├── customer_info（通用-可选）
│   ├── customer_id: str            # 客户号
│   ├── customer_name: str          # 客户姓名
│   ├── id_number: str              # 证件号
│   ├── id_type: enum               # 证件类型
│   ├── phone: str                  # 手机号
│   └── risk_level: str             # 预警等级
│
├── fraud_ext（伪冒特有）
│   ├── call_id: str                # CALLID
│   ├── caller_no: str              # 主叫号
│   ├── is_consumer_self: bool      # 是否消费者本人
│   ├── complainant_name: str       # 投诉人姓名
│   ├── complainant_id: str         # 投诉人证件号
│   ├── complainant_id_type: str    # 投诉人证件类型
│   ├── complainant_phone: str      # 投诉人手机号
│   ├── case_no: str                # 案件编号
│   ├── work_order_category: str    # 工单类别
│   ├── call_purpose: str           # 来电目的
│   ├── is_filed: bool              # 已建案
│   ├── complaint_content: text     # 被投诉内容
│   └── main_demand: text           # 主体诉求
│
├── marketing_ext（市场企划特有）
│   ├── card_list: [str]            # 卡片列表
│   ├── card_name: str              # 卡片名称
│   ├── remark: str                 # 备注（订单号）
│   ├── customer_feedback: text     # 客户反馈情况
│   └── receive_unit: str           # 接单单位
│
├── credit_ext（征信特有）
│   ├── account_type: str           # 账户类型
│   ├── account_no: str             # 账户(微信/他行卡)
│   ├── is_sensitive: bool          # 是否敏感
│   └── overdue_status: str         # 逾期状态
│
└── dispatch_info（派单/回单）
    ├── dispatch_center: str        # 发单中心
    ├── dispatch_dept: str          # 发单部门
    ├── dispatch_handler: str       # 发单经办
    ├── dispatch_date: datetime     # 发单日期
    ├── reply_handler: str          # 回单经办
    ├── reply_date: datetime        # 回单日期
    ├── reply_content: text         # 回单内容
    └── receive_unit: str           # 接单单位
```
