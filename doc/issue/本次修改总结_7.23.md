# 本次修改总结

> 2026-07-23，分支 `feature/dispatch-reply-refactor`

## 后端改动

### 1. Mock 独立化（`ai-engine/data/mock_domain_seed.json` + `ai-engine/models/database.py`）

**问题**：旧 seed 逻辑从 `tickets.json` 提取数据写入 mock 表，造成循环论证——工单写什么 Mock 就查回什么。

**修改**：
- 新增 `ai-engine/data/mock_domain_seed.json`：独立于工单的 5 客户 + 6 卡片 + 3 权益 + 4 交易 + 3 申请数据
- `database.py` 新增 `_seed_from_independent_data()` 函数，优先加载独立种子，工单兜底

### 2. 工具调用 SSE 推送（`ai-engine/orchestrator/orchestrator.py`）

**问题**：`mock_executor.execute()` 执行时无 SSE 事件推送，前端只能看到 ResolutionAgent 完成 → EscalationAgent，中间的工具调用过程是静默的。

**修改**：工具执行前后加入 `push("agent_start")`、`trace.add_step`、`push("agent_complete")`，前端现在能看到 "Tool Executor / 优惠券补发 — 调用成功，证据编号 BENxxx" 的 SSE 事件。

### 3. 数据库清理

- 删除测试工单（T-D-REJECT-01、SMOKE2136421883）及关联子表数据
- 删除测试客户（C-D-ADDR、C-D-COUPON、C-D-MISSING、C29504、C29511）及关联 mock 数据
- 55 张卡片名称从 "Credit Card" 修正为 "银联标准信用卡"

## 前端改动

### 4. SunPilot 去冗余（`frontend/src/page-agent/panel/AgentPanel.vue:131`）

删除回单模式下 SunPilot 的 "开始处理/重新处理" 快捷按钮。该功能与页面主区域的 "启动AI处理" 按钮完全重复。

### 5. PageAgent 三层执行策略（`frontend/src/page-agent/index.ts:23-30`）

更新 system prompt 为分层策略：
- 第一层：收到 PageTask → 走确定性执行（语义工具，不调 LLM）
- 第二层：PageTask 失败 → 引导坐席（不为难 DOM index）
- 第三层：外部遗留页面 → ReAct DOM 探索（LLM 自主观察，兜底）

## 未改动

- 前端其他文件（用户并行开发中，避免冲突）
- ReAct 引擎能力（完整保留，仅调整默认执行优先级）
