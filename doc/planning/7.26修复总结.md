### 1. 发单模块草稿生成失败 ✅

**问题描述**：所有通话记录都无法 AI 辅助发单，显示"来电内容整理失败，请检查服务后重试"

**根本原因**：`scenario_detection.py` 在对场景按优先级排序时，尝试访问 UNKNOWN 场景的 `detection.priority`，但 UNKNOWN 场景没有 detection 配置，导致 `AttributeError`

**修复方案**：
- 文件：`ai-engine/models/scenario_detection.py:163-168`
- 修改：添加过滤逻辑，只处理有有效 detection 配置的场景
```python
valid_scenarios = [
    (name, cfg) for name, cfg in scenarios.items()
    if cfg is not None and isinstance(cfg.get("detection"), dict)
]
sorted_scenarios = sorted(
    valid_scenarios,
    key=lambda item: item[1].get("detection", {}).get("priority", 999)
)
```

**验证**：测试发单流程，草稿生成成功

### 3. PENDING_INFO 重入卡死（最严重） ✅

**问题描述**：回单 AI 处理后卡在"补充信息"状态，补充信息后点击"重新处理"显示处理失败，工单仍然卡在 PENDING_INFO 状态，无法提交回单

**根本原因**：
- PENDING_INFO 重入时，orchestrator 直接加载了旧快照中的 `extract_result`，完全跳过 IntakeAgent
- 用户补充的信息没有被重新提取
- EscalationAgent 基于旧的 `extract_result` 再次判断缺少字段，返回 `needs_more_info=True`
- 形成死循环，工单永远卡在 PENDING_INFO

**修复方案**：
- 文件：`ai-engine/orchestrator/orchestrator.py:123-158`
- 修改：
  - 保留跳过 ClassifierAgent（因为意图不变）
  - **强制重新运行 IntakeAgent** 来提取用户补充的信息
  - 更新日志：`"re-running IntakeAgent to extract supplementary info"`

**代码变更**：
```python
# PENDING_INFO 重入时，必须重新运行 IntakeAgent 来提取补充的信息
# 只跳过 Classifier，不跳过 Intake
logger.info(
    "[Orchestrator] Resumed with intent=%s, re-running IntakeAgent to extract supplementary info",
    intent_result.get("type"),
)
extract_result = await self._run_agent_step(
    "intake_agent",
    "Intake Agent / 接单与信息提取（重入）",
    self.intake_agent,
    IntakeInput(
        ticket_content=ticket_context,
        intent_type=intent_result.get("type", "UNKNOWN"),
        intent_label=intent_result.get("label", "未知"),
        workflow_config=workflow_config,
    ).to_agent_dict(),
    trace,
    push,
)
ctx.extract_result = extract_result
```

**测试验证**：
- 创建测试工单，模拟 PENDING_INFO 流程
- 第一次处理 → `pending_info`（缺少 `repaymentPlan`）
- 补充还款计划信息："客户希望分12期还款，每期2000元"
- 第二次处理 → `pending_human_review` ✅ 成功
