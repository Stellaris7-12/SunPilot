# TicketAgent 当前发现

> 2026-07-23，分支 `feature/dispatch-reply-refactor`

## PLAN2 关键发现

### 真实工单数据

基于招商银行信用卡「综合业务处理门户 FITS」50 张 Demo 截图 OCR 提取：
- 7 大类工单（伪冒 12/13、客户经营 29、市场企划 30、调单扣款 41、征信 42、协商还款 11/71），每类有独立编号前缀
- 每类有独立特有字段：伪冒预防有投诉人信息组+案件编号、市场企划有卡片列表+订单号、征信有逾期状态+是否敏感
- 发单和回单在真实系统中是分离的操作
- 字段对照表见 `doc/requirements/工单字段结构详解.md`

### 架构口径

- 业务 Agent 是业务大脑（管 what），SunPilot/PageAgent 是页面执行层（管 how）
- 确定性 PageTask executor 走快车道，ReAct 只兜底失败或未知场景
- Mock Tools 应模拟独立外部系统，数据独立于工单；当前种子从工单提取是循环论证，R1 修复

### 答辩防线

- 主动说清: 当前 demo 只有 2-3 个场景，700+ 场景是架构设计的泛化能力，全量覆盖是配置工作
- 主动说清: Mock 不是真实银行系统直连，但架构抽象层是正确的
- 主动说清: Schema 校验框架已建但 demo 未全面启用；PolicyLayer 是后续阶段
